# UTH SmartTasks (Week 07 - Final)

✅ MVVM + Room (offline) + Jetpack Compose

## Chức năng
- Màn hình List: hiển thị danh sách task (card màu pastel giống mẫu)
- Màn hình Add New: thêm task (lưu Room local) -> quay lại List và tự cập nhật ngay

## Kiến trúc
- `data/local`: Room (Entity/Dao/Database)
- `data/repository`: Repository
- `ui/list`: List Screen + ViewModel
- `ui/add`: Add Screen + ViewModel
- `ui/theme`: Theme (light)

## Nộp bài
- Push repo lên GitHub
- Nộp URL GitHub của repo theo yêu cầu đề bài.
